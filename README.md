# Apps (portal)

Portal público con un botón por cada app. Se publica con **GitHub Pages** (Settings → Pages → Branch: `main` / root).

Cada app tiene su carpeta lanzadora con:
- `index.html`: muestra la app publicada en Vercel dentro de la página (iframe). La dirección está en una sola línea, fácil de cambiar.
- `manifest.webmanifest` e íconos: para instalarla en el celular.
